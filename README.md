# Google I/O 2026 Countdown

React ile hazırlanmış, tarayıcıda çalışan Google I/O 2026 geri sayım sayfası.
Arayüz; Gemini 3.5, Veo 4 ve Nano Banana 3.5 temalı kartları, 19–20 Mayıs 2026 etkinlik zaman aralığını ve canlı sayaç alanını içerir.

## Çalıştırma

```bash
npm run dev
```

Ardından tarayıcıda `http://localhost:5173` adresini açın.

> Not: Bu proje derleme aracı gerektirmeyen statik bir React demosudur. React ve ReactDOM tarayıcıda CDN üzerinden yüklenir.

## Kontrol

```bash
npm run build
```

Bu komut JavaScript dosyalarının sözdizimini kontrol eder.
