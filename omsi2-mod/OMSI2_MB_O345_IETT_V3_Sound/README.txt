==============================================================
  OMSI 2 - Mercedes Benz O345 İETT Istanbul V3
  Kickdown Motor Sesi + Melodik ZF EcoAMT Sound Mod
  Version: 3.0
==============================================================

AÇIKLAMA / DESCRIPTION:
-----------------------
Bu mod, OMSI 2 bus simülatörü için Mercedes Benz O345 İETT 
Istanbul otobüsüne özel motor ve şanzıman ses paketi içerir.

This mod contains custom engine and transmission sound pack
for the Mercedes Benz O345 İETT Istanbul bus in OMSI 2.

ARAÇ BİLGİLERİ / VEHICLE INFO:
-------------------------------
- Araç: Mercedes-Benz O345
- Motor: Mercedes-Benz OM447 hLA (300 HP)
- Şanzıman: ZF EcoAMT 6 İleri Otomatik
- Operatör: İETT (İstanbul Elektrik Tramvay ve Tünel)
- Versiyon: V3 (Istanbul Livery)

İÇERİK / CONTENTS:
-------------------
Sound/engine/
  - engine_idle.wav      : Motor rölanti sesi (~700 RPM)
  - engine_low_rpm.wav   : Düşük devir sesi (~1200 RPM)
  - engine_mid_rpm.wav   : Orta devir sesi (~1800 RPM)
  - engine_high_rpm.wav  : Yüksek devir sesi (~2200 RPM)
  - kickdown.wav         : Kickdown motor sesi (turbo dahil)
  - turbo_blowoff.wav    : Turbo blow-off / wastegate sesi
  - engine_starter.wav   : Motor marş/çalıştırma sesi

Sound/transmission/
  - zf_shift_up.wav      : ZF EcoAMT vites yükseltme sesi
  - zf_shift_down.wav    : ZF EcoAMT vites düşürme sesi

Sound/misc/
  - air_brake.wav        : Havalı fren bırakma sesi
  - door_open.wav        : Pnömatik kapı açma sesi
  - door_close.wav       : Pnömatik kapı kapama sesi
  - horn.wav             : Çift tonlu korna sesi
  - melodic_chime.wav    : Melodik kalkış zili sesi

Config/
  - sound.cfg            : Ses yapılandırma dosyası

KURULUM / INSTALLATION:
-----------------------
1. Bu klasörü açın / Extract this folder
2. "Sound" ve "Config" klasörlerini kopyalayın
3. OMSI 2 kurulum dizinine gidin:
   C:\Program Files (x86)\Steam\steamapps\common\OMSI 2\
4. Vehicles\MB_O345\ klasörünü bulun
5. Mevcut Sound klasörünü yedekleyin (backup yapın!)
6. Dosyaları yapıştırın / Paste the files

KALDIRMA / UNINSTALL:
---------------------
1. Yedeklediğiniz orijinal Sound klasörünü geri yükleyin
   Restore your backed-up original Sound folder
